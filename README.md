# Obrázky plánov (pomocná vetva)

Návrhy scén pre plány v appke Viking's Workout, ktoré nemali vlastný obrázok.

cez stable-diffusion.cpp na GitHub Actions. Výsledky sú vo vetve `obrazky-planov-vysledky`.
Táto vetva nesúvisí s webom Techniky (ten sa nasadzuje len z `main`).
